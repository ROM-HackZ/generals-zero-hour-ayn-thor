# Thor RTS — easier matching selection

Double-pressing A can be fiddly with cursor snap. You can now select one unit,
hold **LT and click the left stick (L3)** to select matching units on screen.
The cursor can be anywhere. Pressing it again stays limited to the screen.
Plain L3 still centres the camera on your selection.

With a mixed selection, the shortcut adds visible matches for each selected
type. It leaves menus, building placement and ability targeting alone. Double A
and double-tap still work. This includes all previous preview fixes and keeps
the original 30 Hz simulation.

## Install / update

Download `Thor-RTS-0.1.0-alpha.5.apk`. Installer 0.1.0 still automatically gets
alpha.1: choose this APK under **Advanced → Local APK**, and tick **App update
only** if your game files are already installed. Save your match before updating.
The same signing key keeps app data and saves during an in-place update.
No game files or test app are included.
